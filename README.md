# Titanic Survival Prediction

A reproducible binary-classification study using the supplied Kaggle Titanic training data. The workflow compares a majority-class baseline, logistic regression, and random forest; selects using cross-validation on the development split; and reports a single untouched holdout evaluation.

## Results

Results are generated by the commands below and saved under `artifacts/`. They describe this dataset and fixed random split only; they do not establish performance on a new population or on the Kaggle test labels, which are not provided.

| Model | Holdout balanced accuracy | Holdout accuracy |
|---|---:|---:|
| Logistic regression (selected) | 0.822 | 0.838 |
| Majority-class baseline | 0.500 | 0.615 |

On the fixed 179-row holdout, logistic regression had ROC AUC 0.880, precision 0.813, and recall 0.754. In five-fold development cross-validation, logistic regression averaged 0.806 balanced accuracy (SD 0.021); random forest averaged 0.802 (SD 0.029). The selection used only the development partition. Full-precision metrics, split metadata, and confusion matrix are saved in `artifacts/metrics.json`; cross-validation results are in `artifacts/cv_results.csv`.

## Reproduce

Requires Python 3.11 or newer.

```bash
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python titanic.py eda
python titanic.py train
python titanic.py evaluate
python titanic.py predict
python scripts/execute_notebook.py
```

`eda` validates the input files and saves exploratory figures. `train` partitions the labeled data once into stratified development and holdout sets, fits preprocessing inside each cross-validation fold, and selects among the documented candidate models. `evaluate` reports the holdout metrics and errors. `predict` fits the selected pipeline on all labeled rows and writes predictions for the unlabeled Kaggle test file. The test file contains no survival labels, so its accuracy cannot be measured here.

## Method

- The random seed and split sizes are recorded with the outputs.
- Numeric imputation, categorical imputation, and one-hot encoding are fitted within scikit-learn pipelines to avoid fitting preprocessing on validation rows.
- Five-fold stratified cross-validation compares logistic regression and random forest with a `DummyClassifier` baseline. Balanced accuracy is the selection metric.
- The holdout split is kept out of model selection and is evaluated once after selection.
- `Fare`, `Age`, `Embarked`, and `Cabin` are handled with explicit preprocessing. Engineered features include family size, whether traveling alone, and passenger title.

## Repository contents

```text
data/                         supplied train, test, and sample-submission CSVs

scripts/execute_notebook.py  execute notebook cells for CI/reproduction
tests/                        data and pipeline checks

artifacts/                    generated metrics, predictions, and figures
```

Generated artifacts are reproducible from the included CSV files. The serialized fitted model is intentionally not required; prediction recreates the pipeline from source and data.

## Limitations

This is a small educational dataset with historical labels and possible sampling bias. The holdout is one split from the same supplied training file, not an independent external test. The Kaggle test set has no labels here. The project does not claim causal explanations, calibrated risk estimates, or suitability for real passenger-safety decisions.
